## Task 2 — Assertions, Aliases & Custom Commands

Goal: Practice advanced Cypress features including assertion types, element aliases, custom commands, and lifecycle hooks.

### Test Cases

#### Assertion Practice — `cypress/e2e/task2/assertions.cy.js`

| Test | Assertion Type | Description |
|---|---|---|
| Assertion 1 | `should('be.visible')` | Login button is visible on page load |
| Assertion 2 | `should('have.text', '...')` | Page logo has correct text content |
| Assertion 3 | `should('have.attr', '...')` | Username input has correct placeholder attribute |
| Negative Assertion | `should('not.exist')` | Error message does not exist on fresh page load |

#### Aliases & Custom Commands — `cypress/e2e/task2/aliases.cy.js`

| Test | Feature | Description |
|---|---|---|
| Alias practice | `.as()` and `@alias` | Save input fields as aliases and reuse them |
| Custom command | `cy.login()` | Reusable login command replaces repeated steps |
| Negative assertion | `should('not.exist')` | Confirm error element is absent |
| Bonus — cy.contains() | `cy.contains()` | Find elements by visible text content |

### Custom Command — `cypress/support/commands.js`

```js
Cypress.Commands.add('login', (username, password) => {
  cy.get('#user-name').type(username)
  cy.get('#password').type(password)
  cy.get('#login-button').click()
})
```

Usage in tests:
```js

```

## Task 2 — Reflection

During this lab, the most challenging part was working with element aliases using `.as()` combined with negative assertions. Initially, I tried to save an element that did not exist on the page as an alias and then assert `not.exist` on it. Cypress threw a timeout error because it tries to find the element before saving the alias, which fails when the element is absent. After investigating the error, I understood that aliases should only be used on elements that are confirmed to exist on the page. The fix was to use `cy.get().should('not.exist')` directly without creating an alias. Another challenge was the `cy.screenshot()` buffer overflow error in Cypress 15, which was caused by inconsistent page heights across different pages. Setting a fixed `viewportWidth` and `viewportHeight` in `cypress.config.js` resolved the issue completely by forcing all tests to run at a consistent 1280x720 resolution.
